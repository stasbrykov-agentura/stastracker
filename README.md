# Стастрекер

Личный органайзер целей и задач по логике GTD: Место хаоса, категории и проекты с целями, контексты, план дня, избранное, корзина.

- Приложение: `index.html` (один файл), офлайн-оболочка `sw.js`, манифест для установки на экран «Домой».
- Облако: Supabase. Схема базы — `supabase/schema.sql`.
- Синхронизация: локальная копия на каждом устройстве, слияние по правилу «последняя правка побеждает» отдельно по каждому полю.
